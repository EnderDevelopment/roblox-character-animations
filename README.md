# Character Animations

This project contains a Roblox script for character animations that includes walking, respawn, mage running, jumping, climbing, and ninja swimming poses. The respawn animation is visible to others.

## Install

1. Download the project files from GitHub.
2. Open your Roblox Studio project.
3. Place the `CharacterAnimations.server.lua` script in the ServerScriptService.
4. Place the `MageRunCommand.client.lua` script in the StarterPlayerScripts.
5. Replace the placeholder animation IDs in the scripts with your actual animation IDs.

## Use

1. Launch your Roblox game.
2. The character will automatically play the walking animation.
3. Press the 'R' key to trigger the mage run animation.
4. The character will play the appropriate animations for jumping, climbing, and swimming.
